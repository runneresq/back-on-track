Connect Garmin — new personal API

Garmin connected — data pulled automatically

Garmin now offers a personal API — any Garmin user can get an API key in seconds. Connect once and the app pulls your VO2Max, HRV, Endurance Score, and activities automatically.

What gets pulled automatically: VO2Max · Endurance Score · HRV 7-day avg · Resting HR · Recent run activities (distance, HR, pace)

Step 1 — Get your personal API key

  1. Open connect.garmin.com → Settings → Personal API Token
  2. Click Generate token
  3. Copy the token that appears
  4. Paste it below

Stored locally in your browser only — never sent anywhere except Garmin's own servers.
